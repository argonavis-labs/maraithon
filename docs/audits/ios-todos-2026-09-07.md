## Changes

- `df41636a` fixes chat decoding. The server uses namespaced client correlation
  keys for assistant replies and prepared-action results; these are strings,
  while the iOS decoder required UUIDs. A single such latest message prevented
  the entire thread list from decoding. Production read-only execution `nw6r8`
  found two `assistant-run-final:` keys among five latest mobile-thread messages.
  iOS now retains UUID correlation keys for matching optimistic sends and uses
  each message's canonical server ID for other replies.
- Response validators are stored only after successful decoding. Chat sync
  retains its validator only after the local merge saves, and a new cache key
  forces one fresh fetch for devices affected by the old failed-decode cache.
- `643e13a6` makes Todos the first and default tab. People and Stream are removed
  from navigation; older links to those tabs open Todos. Today and Chat remain.
- Todo rows show a completion circle, title, up to two lines of context, and a
  due date when present. The previous stack of decision text, suggested actions,
  priority pills, contact badges, and source labels is removed from each row.
  Full context remains available through the row's native navigation link.
- The horizontal filter strip is replaced by a toolbar menu. Active is the
  default, with completed, snoozed, and other filters still available. Creation,
  editing, and detail labels use Todo terminology.
